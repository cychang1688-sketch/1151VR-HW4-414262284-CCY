# 1151VR-HW4-414262284-張智瑜

## 專案說明
本次作業使用 Unity 製作一款 3D 飛行閃避障礙物遊戲，匯入 3D 飛行器模型與障礙物模型，並利用 C# 程式控制障礙物持續生成及朝飛行器方向移動。玩家可在電腦上透過滑鼠游標控制飛行器上下左右移動，也能在 Android 手機上使用手指於螢幕上滑動來操控飛行器，閃避迎面而來的障礙物。遊戲畫面左上角會顯示碰撞次數（Hits）與成功閃避次數（Passed），當飛行器碰到障礙物時，Hits 會增加；成功閃避障礙物時，Passed 則會增加，而障礙物經過後會自動消失。此外，遊戲加入飛行、碰撞及成功通過三種音效，並將畫面設定為手機直向模式。最後完成 Android APK 建置與手機實際測試，確認遊戲功能皆能正常運作，並將專案上傳至 GitHub，同時錄製遊戲操作影片上傳至 YouTube。
